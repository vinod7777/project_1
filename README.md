## About C Programming
C is a general-purpose, procedural programming language widely used for system programming, operating systems, and embedded applications. It provides low-level memory access, fast execution, and a structured approach to problem-solving.

### Key Concepts Covered
- **Basics:** Variables, data types, operators, and input/output functions (`printf`, `scanf`).
- **Control Flow:** Conditional statements (`if-else`, `switch`) and loops (`for`, `while`, `do-while`).
- **Functions & Arrays:** Modular programming with functions, 1D/2D arrays, and string manipulation.
- **Pointers & Memory:** Pointer arithmetic, dynamic memory allocation, and structures.

### How to Compile and Run
To run any C program in this repository using the GCC compiler, use the following commands in your terminal:

```bash
gcc filename.c -o output
./output
```
